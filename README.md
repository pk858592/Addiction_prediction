📵 Social Media Addiction App

A powerful, privacy-friendly app designed to help users regain control over their social media usage, build healthier digital habits, and improve focus and productivity.

🚀 Overview

The Social Media Addiction App helps users:

Track social media usage in real time

Set daily limits and goals

Block or restrict distracting apps

Monitor behavioral patterns

Build healthier digital routines

Whether you're trying to reduce screen time, improve focus, or take a full digital detox, this app provides the tools and insights to make it happen.
